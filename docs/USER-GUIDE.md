# Getting started with NoteChange

1. Download the installer from GitHub Releases and open it. The app creates a desktop shortcut. This preview is unsigned; review any Windows publisher prompt before proceeding.
2. Open NoteChange and press **Sign in to iCloud**. Sign in on Apple's page and approve the request on your iPhone if Apple asks.
3. Open a note, then press **Add this note**. Check it in the preview. Return to iCloud and repeat to add more notes.
4. Choose **Automatic**, **Clean document**, **Recipe** or **Book chapter**. Layout changes the appearance; the original words stay intact.
5. Press **Save Word document**, **Save PDF** or **Copy for email**.

## Recipes

Automatic mode recognises existing labels such as Ingredients and Method. It applies headings without inventing ingredients, changing quantities or rewriting instructions. Always compare quantities and wording in the preview.

## Chapters and collections

Select a note in the collection to preview it. Move up/down changes export order. Enable **Export all added notes as one document** to combine them. Word and PDF start each note on a new page. Save a project before closing to keep the collection; open the project to continue later.

## Email

Copy for email keeps formatting. Open a new email and paste into the message area. The title is in the message, and the subject remains empty. Add the recipient and check before sending. Open email uses a plain text draft for shorter notes; email draft files behave differently across email apps.

## When capture is unavailable

Open the note, copy its contents, return to NoteChange and press **Paste note**. Locked notes must be opened in Apple Notes first. Notes saved only on a device rather than iCloud are not available on the web. Save unsupported attachments separately. Check warnings for pictures and tables before exporting.

## Updates and privacy

Save a project before an update restart. Sign out of iCloud clears the Apple browser session on this computer. Clear collection removes the current workspace, not your original Apple notes. See [Privacy](PRIVACY.md) for local files, projects and clipboard handling.
