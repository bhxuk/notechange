YOUR WORDS STAY YOUR WORDS

A formatting helper.
No rewriting required.

NoteChange processes notes on your computer. There's no NoteChange cloud account and no AI rewriting. You decide what to save and share. Apple sign-in still connects directly to Apple.

A few useful details

Do I need Microsoft Word?

NoteChange creates a .docx file. You need an app that supports Word documents to open and edit it.

Does it change the original note?

No. Capture reads the selected note; formatting and saving happen in NoteChange.

Will all pictures and attachments transfer?

Basic text formatting, lists and tables are supported in the first implementation. Pictures depend on capture and format support. Attachments and complex tables may need separate handling. Check the preview and any warning before saving.

Is it ready to install?

Download the Windows public preview from GitHub Releases. Real Apple sign-in and live note capture still need acceptance testing. Read the release notes before everyday use.
