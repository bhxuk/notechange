# Security reporting

Do not include Apple passwords, session cookies, real notes or personal attachments in issues or logs.

For sensitive issues, use GitHub's private vulnerability reporting if it is enabled for this repository, or contact the repository owner privately. If no private route is available, open a minimal issue asking for a private contact channel without revealing the vulnerability or personal data.

Supported versions: the latest published preview. The Apple Notes adapter is a read-only web-page adapter rather than an official Apple Notes API; compatibility must be verified against current Apple pages. Production use requires real-account acceptance testing and a release/signing review.
